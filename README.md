# מנהל קריאה ומנוע המלצות חכם

אפליקציית ווב בקובץ אחד (`index.html`) לניהול ספרים שקראתם ולקבלת המלצות. כל ספר, בספרייה ובהמלצות, נבדק מול Google Books או Open Library לפני שהוא מוצג.

## הרצה
- **GitHub Pages:** Settings → Pages → Deploy from branch, ואז לפתוח את הכתובת בטלפון.
- **מקומית:** לפתוח את `index.html` בדפדפן. לא צריך התקנה, שרת או מפתח API.

> צריך לפתוח את הקובץ בדפדפן רגיל. ארגז החול של Claude Artifacts חוסם קריאות רשת ל-`googleapis.com` ול-`openlibrary.org`, ולכן חיפוש ספרים לא יעבוד שם.

## ספרייה משפחתית ו-AI (רשות)
חיבור לשרת משפחתי חינמי ב-Cloudflare מוסיף:
- **סנכרון:** כל המשתמשים והספרים בכל הטלפונים.
- **Claude:** המלצות חכמות מבקשה חופשית, זיהוי חכם של ספרים שהחיפוש לא מצא, הוספת ספרים מפסקת טקסט חופשי, והשלמת תקציר וזמינות. Claude קורא ביקורות ותקצירים רק באתרים אמינים (הוצאות, חנויות, מוספי ספרות). כל ספר שהוא מציע נבדק מול Google Books / Open Library, ומה שלא אומת נפסל.

מדריך הקמה: [worker/README.md](worker/README.md).

## איך זה עובד
0. **משתמשים:** כשפותחים את האפליקציה בוחרים "של מי הספרייה?", בלי סיסמה. לכל משתמש יש ספרייה, דירוגים, תגיות, רשימות והמלצות משלו. הנתונים נשמרים במכשיר; להעברה בין מכשירים משתמשים בגיבוי ובייבוא. ספרייה שהייתה במכשיר לפני שנוספו משתמשים עוברת למשתמש הראשון שנוצר.
1. **הוספה:** שם ספר בעברית או באנגלית, ISBN, או קישור (Google Books, Open Library, או כל קישור שמכיל ISBN). קודם נשלחת שאילתה ל-Google Books (`langRestrict=iw` לטקסט בעברית, ואם אין מספיק תוצאות, שאילתה כללית). אם יש שגיאה, חסימת מכסה (429) או מעט תוצאות, עוברים ל-Open Library. לשמות בעברית יש גם גשר דרך Wikidata: שם עברי ← שם המקור והמחבר ← רשומת Open Library. אם אין רשומה כזו, מוצגת רשומת Wikidata עם תקציר מוויקיפדיה, ומסומן שהתקציר משם.
   - **רשימה של כמה ספרים:** מדביקים רשימה חופשית, ספר בכל שורה (אפשר "שם - מחבר", מספור או תבליטים). כל ספר נבדק ברקע, ואז עוברים ספר-ספר: בוחרים, מדרגים, מדלגים או מתקנים את החיפוש. ההתקדמות נשמרת גם אחרי רענון.
   - **מהדורות והדפסות:** תוצאות של אותו ספר מקובצות לכרטיס אחד, עם רשימת ההדפסות (הוצאה, שנה, עמודים, שפה, ISBN וכריכה). ב-Open Library המהדורות נטענות לפי דרישה.
   - **חיפוש גמיש:** אפשר לכתוב שם ומחבר יחד, רק שם משפחה, או באיות אחר. אם אין התאמה טובה, האפליקציה מנסה לפצל בין שם הספר לשם המחבר, לחפש לפי שם המשפחה ולנסות כתיב עברי חלופי (וו/ו, יי/י, ב/וו, כתיב מלא/חסר). התוצאות מדורגות לפי התאמה גמישה (תחיליות, אות-שתיים הבדל).
2. **שער אישור:** מוצגים רק מועמדים שחזרו מה-API (כריכה, שם, מחבר, שנה, תקציר רשמי). שום דבר לא נשמר בלי לחיצה על "זה הספר שלי".
3. **דירוג ותגיות:** 1–5 כוכבים ותגיות, עם תגיות מוצעות שנגזרות מהקטגוריות של הספר.
4. **המלצות:** שאלון קצר (מצב רוח, קצב, נושאים להימנע מהם, אורך) ופרופיל טעם שנבנה מספרים שדורגו 4–5 כוכבים (מחברים, קטגוריות, תגיות), כך:
   - שאילתות API אמיתיות לפי מחבר, קטגוריה, תגית ומצב רוח
   - סינון של ספרים שכבר ברשימה, ספרים שסומנו "לא מעניין", מחברים שדורגו נמוך, נושאים להימנע מהם, אורך ושפה
   - שקלול ציון
   - **אימות חוזר** של כל מועמד לפי המזהה שלו במקור (`volumes/{id}` או `works/{key}.json`)
   מועמד שלא עובר את האימות, או שאין לו תקציר רשמי, נפסל. לכל המלצה מוצג הסבר שמבוסס רק על נתונים אמיתיים.
   - **היסטוריה:** כל שיחת המלצות נשמרת (תשובות, השיחה וההמלצות), ואפשר לחזור אליה.
   - **שפה:** ברירת מחדל לכל משתמש: עברית, עברית ואנגלית, אנגלית, כל שפה או אוטומטי.
   - **זמינות:** מוצג רק מה שה-API מאשר (ספר דיגיטלי ב-Google Play, השאלה ב-Open Library, מהדורה מודפסת עם ISBN), ובנוסף קישורי חיפוש ל-e-vrit, Storytel, עברית, סטימצקי, צומת ספרים ו-Audible.
5. **אחסון:** `localStorage` (מפתח `verified_reading_tracker_db_v1`) ועותק ב-IndexedDB, סנכרון בין לשוניות, ובקשת אחסון קבוע. יש ייצוא ל-JSON או לטקסט, העתקה ללוח, וייבוא (מיזוג או החלפה).

**מפתח Google Books (מומלץ מאוד):** הגישה בלי מפתח משתמשת במכסה יומית אחת שמשותפת לכל העולם, והיא בדרך כלל כבר מנוצלת. מפתח אישי הוא בחינם ומאפשר 1,000 חיפושים ביום. מסך "גיבוי נתונים" כולל מדריך קצר להשגת מפתח וכפתור שבודק שהוא עובד.
