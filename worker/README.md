# הקמת הספרייה המשפחתית (סנכרון + המלצות חכמות)

השרת המשפחתי הוא קובץ אחד, [`worker.js`](worker.js), שרץ בחשבון Cloudflare חינמי. הוא עושה שני דברים:

- **סנכרון:** כל המשתמשים, הספרים, הדירוגים וההיסטוריה משותפים לכל הטלפונים שמחוברים עם אותו קוד.
- **גישה ל-Claude:** מפתח ה-API נשמר בשרת ולא בטלפונים. החיפוש ברשת מוגבל לרשימת האתרים האמינים שבראש הקובץ. אפשר לערוך את הרשימה (`TRUSTED_DOMAINS`).

ההקמה לוקחת בערך 15 דקות, ואפשר לעשות אותה גם מהטלפון.

## 1. מפתח API של Anthropic

1. נכנסים ל-https://console.anthropic.com ונרשמים.
2. **Billing:** מוסיפים קרדיט, למשל 10 דולר. המלצה אחת עולה בערך 0.3–0.6 דולר.
3. מומלץ: ב-**Limits** מגדירים תקרת הוצאה חודשית.
4. **API Keys ← Create Key.** מעתיקים את המפתח (מתחיל ב-`sk-ant-`) ושומרים אותו לשלב 4.

## 2. חשבון Cloudflare ויצירת השרת

1. נרשמים בחינם ב-https://dash.cloudflare.com.
2. בתפריט: **Workers & Pages ← Create ← Create Worker** (או "Start with Hello World").
3. נותנים שם, למשל `books-family`, ולוחצים **Deploy**.
4. לוחצים **Edit code**, מוחקים את כל הקוד שמופיע, ומדביקים במקומו את כל התוכן של [`worker.js`](worker.js). בגיטהאב: פותחים את הקובץ, לוחצים **Raw**, מסמנים הכול ומעתיקים.
5. לוחצים **Deploy**.

## 3. מאגר נתונים (KV)

1. בתפריט: **Storage & Databases ← KV** (לפעמים נקרא Workers KV) **← Create**, ונותנים שם, למשל `books-library`.
2. חוזרים ל-Worker: **Settings ← Bindings ← Add ← KV namespace.**
   - Variable name: `LIBRARY` (בדיוק כך, באותיות גדולות)
   - בוחרים את `books-library`
   - שומרים ולוחצים **Deploy**.

## 4. סודות

ב-Worker: **Settings ← Variables and Secrets ← Add.** מוסיפים שני משתנים מסוג **Secret**:

| שם | ערך |
|---|---|
| `ANTHROPIC_API_KEY` | המפתח משלב 1 |
| `FAMILY_CODE` | קוד שתבחרו לספרייה, למשל `ספרים-4827`. אפשר גם בעברית. |

שומרים ולוחצים **Deploy**.

## 5. חיבור הטלפונים

1. מעתיקים את כתובת ה-Worker מהדף שלו. היא נראית כך: `https://books-family.XXXX.workers.dev`
2. באפליקציה, בכל טלפון: **גיבוי נתונים ← ספרייה משפחתית**. מדביקים את הכתובת והקוד ולוחצים **חיבור**.
   - גם במסך "של מי הספרייה?" יש כפתור לחיבור הטלפון.

בחיבור הראשון, המשתמשים והספרים שכבר יש בטלפון מתמזגים עם מה שיש בשרת. אף משתמש לא נמחק.

## בטיחות ועלויות

- **הרשאות:** מי שיודע את הקוד יכול לקרוא ולערוך את הספרייה, וזה כל ה"הזדהות". לכן כדאי לבחור קוד שקשה לנחש.
- **גבולות שימוש:** השרת מקבל בקשות רק מהאתר של האפליקציה, ומגביל את השימוש ב-Claude ל-150 קריאות ביום (`DAILY_AI_LIMIT`).
- **גיבוי:** השרת שומר גיבוי יומי אוטומטי של הספרייה, והגיבויים נשמרים 30 יום.
- **פרטיות:** כשמבקשים המלצה, רשימת הספרים, הדירוגים וההערות נשלחים ל-Claude (Anthropic) לצורך ההמלצה.
